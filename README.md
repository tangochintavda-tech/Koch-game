# Коч Братан — кликер

Мобильная HTML-игра-кликер. Всё (картинки и звуки) встроено прямо в `index.html`, поэтому работает без дополнительных файлов.

## Запуск на GitHub Pages
1. Создай репозиторий на GitHub и загрузи в него все файлы из этой папки.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты игра откроется по адресу `https://ВАШ_НИК.github.io/НАЗВАНИЕ_РЕПО/`.

Звук включается после первого касания экрана (требование браузеров).
